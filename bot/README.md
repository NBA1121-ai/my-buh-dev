# Telegram-бот EsepOnline

Бот работает с той же базой, что и сайт (`db.json` в репозитории данных на GitHub):

- **📦 Остатки** — остатки на складе по группам (продукция, материалы, товары), считаются так же, как на сайте.
- **💰 Долги** — кто нам должен и кому должны мы, с учётом «Ввода остатков по расчетам»; карточка контрагента.
- **📄 Новый документ** — счёт на оплату, накладная, акт приёма-передачи, акт выполненных работ, счёт-фактура.
  Контрагент и позиции выбираются кнопками или поиском; можно добавить нового контрагента и новый товар/услугу.
  После «Сформировать PDF» документ сразу записывается на сайт, а PDF приходит в чат — его пересылают клиенту.
- Из счёта одной кнопкой делается накладная или акт, из накладной — счёт-фактура (номер из общего счётчика сайта).
- Накладная проводится, только если хватает остатка; иначе бот предлагает сохранить её черновиком.
- Доступ: администраторы из `ADMIN_IDS`; сотрудник пишет боту `/start`, администратору приходит запрос с кнопкой «Разрешить».

## Как устроено

| Файл | Что делает |
| --- | --- |
| `src/index.js` | Cloudflare Worker: вебхук Telegram (`/webhook`) и одноразовая настройка (`/setup`) |
| `src/bot.js` | Меню, мастер документов, справки, доступ сотрудников |
| `src/logic.js` | Учётная логика, перенесённая с сайта: остатки, долги, нумерация, суммы |
| `src/pdf.js` | Печатные формы в PDF (шрифт DejaVu Sans — кириллица) |
| `src/github.js` | Чтение/запись `db.json`; при конфликте с сайтом перечитывает файл и повторяет запись |
| `test/run.mjs` | Эмулятор Telegram + GitHub + D1: `node test/run.mjs <db.json> <папка для PDF>` |

Сессии диалога и список сотрудников хранятся в Cloudflare D1 (база `esep-bot`).

## Запуск

1. **Бот в Telegram.** @BotFather → `/newbot` → имя и username → скопировать токен (это секрет).
2. **Свой Telegram ID.** Написать @userinfobot → число `Id`.
3. **Токен GitHub.** github.com → Settings → Developer settings → Fine-grained tokens → Generate:
   Repository access — *Only select repositories* → `my-buh-dev-data` (для основного сайта — `my-buh`);
   Permissions → *Contents: Read and write*.
4. **Cloudflare.** Зарегистрироваться на dash.cloudflare.com, подключить тариф **Workers Paid** ($5/мес):
   формирование PDF занимает 50–200 мс процессорного времени, а бесплатный тариф даёт только 10 мс на запрос.
5. **База D1.** Storage & Databases → D1 → Create → имя `esep-bot` → скопировать *Database ID* и вписать в `wrangler.toml`.
6. **Воркер.** Workers & Pages → Create → Import a repository → `NBA1121-ai/my-buh-dev` → Root directory: `bot` → Deploy.
7. **Секреты** (Worker → Settings → Variables and Secrets → Add → Secret):
   `BOT_TOKEN` — токен из п.1, `GITHUB_TOKEN` — из п.3, `ADMIN_IDS` — ID из п.2 (несколько — через запятую),
   `WEBHOOK_SECRET` — любая длинная случайная строка из латинских букв и цифр.
8. Открыть в браузере `https://esep-bot.<ваш-поддомен>.workers.dev/setup?key=<WEBHOOK_SECRET>` — должно быть «Вебхук: установлен», «Доступ к базе: ok».
9. Написать боту `/start`.

**Переключить на основной сайт:** в `wrangler.toml` поставить `DATA_REPO = "my-buh"` и выдать токену доступ к `my-buh`.
