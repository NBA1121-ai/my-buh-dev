# 1C Бухгалтерия - Облачная система учета

Полнофункциональная бухгалтерская система с облачным хранением данных, авторизацией и синхронизацией между устройствами.

## Возможности

- **Банк и касса** - платежные поручения, кассовые ордера, выписки, конвертации
- **Покупки** - счета от поставщиков, поступления, возвраты, корректировки, ГТД, доверенности
- **Продажи** - счета покупателям, реализация, розничные продажи, отчеты комиссионеров
- **Склад** - остатки, перемещения, инвентаризация, оприходование, списание
- **Производство** - спецификации, требования-накладные, отчеты за смену, закрытие месяца
- **Зарплата и кадры** - сотрудники, приемы, увольнения, отпуска, начисление зарплаты
- **Справочники** - контрагенты, номенклатура, склады, должности и другие
- **Отчеты** - движение денежных средств, кассовая книга, валовая прибыль, анализ ФОТ
- **Печатные формы** - ТОРГ-12, УПД, счета-фактуры, акты, кассовая книга и другие

## Технологии

- **Frontend** - HTML/CSS/JavaScript (адаптивный дизайн для мобильных)
- **Backend** - Supabase (PostgreSQL + Auth + Realtime)
- **Хранение** - облачная база данных с автоматическими резервными копиями
- **Синхронизация** - real-time между устройствами

## Быстрая настройка

### 1. Создайте проект в Supabase (бесплатно)

1. Зайдите на [supabase.com](https://supabase.com) и создайте аккаунт
2. Нажмите **New Project**
3. Выберите имя и пароль для базы данных
4. Выберите регион (ближайший к вам)
5. Дождитесь создания проекта (~2 минуты)

### 2. Создайте таблицы в базе данных

1. В Supabase Dashboard перейдите в **SQL Editor**
2. Нажмите **New Query**
3. Скопируйте и вставьте содержимое файла `setup/schema.sql`
4. Нажмите **Run**

### 3. Настройте конфигурацию

1. В Supabase Dashboard перейдите в **Settings** -> **API**
2. Скопируйте **Project URL** и **anon/public key**
3. Откройте файл `js/config.js` и вставьте свои значения:

```javascript
const SUPABASE_URL = 'https://ваш-проект.supabase.co';
const SUPABASE_ANON_KEY = 'ваш-anon-key';
```

### 4. Настройте авторизацию

1. В Supabase Dashboard -> **Authentication** -> **Providers**
2. Убедитесь что **Email** включен
3. По желанию отключите **Confirm email** в **Authentication** -> **Settings** для упрощения регистрации

### 5. Разверните сайт

**Вариант A - Vercel (рекомендуется):**
1. Зайдите на [vercel.com](https://vercel.com)
2. Подключите GitHub репозиторий
3. Deploy!

**Вариант B - GitHub Pages:**
1. В репозитории: Settings -> Pages
2. Source: Deploy from a branch
3. Branch: main, folder: / (root)
4. Save

**Вариант C - Netlify:**
1. Зайдите на [netlify.com](https://netlify.com)
2. Drag & drop папку проекта или подключите GitHub

## Безопасность

- Все данные защищены Row Level Security (RLS) - каждый пользователь видит только свои данные
- Пароли хешируются на стороне Supabase (bcrypt)
- Данные передаются по HTTPS
- Автоматические ежедневные бэкапы базы данных (Supabase)
- Возможность создания ручных резервных копий из интерфейса
