# 1s Бухгалтерия - Облачная система учета

Полнофункциональная бухгалтерская система с хранением данных в GitHub.

## Возможности

- **Банк и касса** - платежные поручения, кассовые ордера, выписки, конвертации
- **Покупки** - счета от поставщиков, поступления, возвраты, корректировки, ГТД, доверенности
- **Продажи** - счета покупателям, реализация, розничные продажи, отчеты комиссионеров
- **Склад** - остатки, перемещения, инвентаризация, оприходование, списание
- **Производство** - спецификации, требования-накладные, отчеты за смену, закрытие месяца
- **Зарплата и кадры** - сотрудники, приемы, увольнения, отпуска, начисление зарплаты
- **Справочники** - контрагенты, номенклатура, склады, должности и другие
- **Отчеты** - ДДС, кассовая книга, валовая прибыль, анализ ФОТ
- **Печатные формы** - ТОРГ-12, УПД, счета-фактуры, акты и другие

## Как это работает

- **Хостинг** - GitHub Pages (бесплатно)
- **Хранение данных** - GitHub репозиторий (ветка `data`)
- **Бэкапы** - каждое сохранение = git коммит = полная история изменений
- **Синхронизация** - данные доступны с любого устройства
- **Авторизация** - GitHub Personal Access Token
- **Мобильная версия** - адаптивный дизайн

## Быстрый старт

### 1. Создайте GitHub Token

1. Откройте [github.com/settings/tokens/new](https://github.com/settings/tokens/new)
2. **Note:** `1c-accounting`
3. **Expiration:** `No expiration`
4. **Scopes:** поставьте галочку на `repo`
5. Нажмите **Generate token**
6. Скопируйте токен (начинается с `ghp_`)

### 2. Откройте сайт и войдите

1. Перейдите на https://nba1121-ai.github.io/1c-accounting/
2. Вставьте токен и нажмите "Войти"
3. Готово! Токен сохраняется в браузере.

## Безопасность

- Токен хранится только в localStorage вашего браузера
- Токен НЕ сохраняется в репозитории
- Данные доступны только владельцу токена
- Полная история изменений в Git
