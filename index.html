Токен сохраняется только в вашем браузере и не передаётся третьим лицам.


Как создать GitHub Token за 1 минуту:
  1. Откройте github.com/settings/tokens/new
  2. Note: введите 1c-accounting
  3. Expiration: выберите No expiration (бессрочный)
  4. Scopes: поставьте галочку на repo (полный доступ к репозиториям)
  5. Нажмите "Generate token" внизу страницы
  6. Скопируйте токен (начинается с ghp_) и вставьте выше

Важно: токен показывается один раз! Сохраните его в надёжном месте.

Данные хранятся в GitHub с полной историей изменений
